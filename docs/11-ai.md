# 11 — AI Specification

**Routes.** `/ai/analyst` · `/ai/chat` · `/ai/strategy`

AI is an assistant to the ANALYSE and IMPROVE steps. It never places a trade,
never starts a bot, and never claims to predict. Its output is always framed as
an interpretation of stated inputs, and every claim it makes must be traceable
to data the user can see on screen.

## Language rules (binding)

Permitted: "the last 500 ticks show…", "this configuration has historically…",
"the indicators currently disagree because…". Forbidden anywhere in prompt,
response rendering, or UI copy: "will", "guaranteed", "signal to buy",
"prediction", "sure thing", win-rate promises, or any statement about the next
tick. Responses that violate the rules are rendered with the offending claim
flagged rather than silently shown.

```
│  • digit distribution (1000) · realised volatility · session             │
├ READING ─────────────────────────────────────────────────────────────────┤
│ Trend        ▲ up, weak      RSI 61 · price above 20MA, below 50MA slope │
│ Momentum     → flat          MACD histogram contracting since 09:12      │
│ Volatility   ▲ elevated      ATR 14 is 1.6× its 20-period mean           │
│ Structure    support 1231.4 · resistance 1239.8 (touched 3× today)       │
├ INTERPRETATION ──────────────────────────────────────────────────────────┤
│ Prose paragraph. Each factual clause carries a superscript linking to the│

│ What would invalidate this reading · what is ambiguous · what is missing │

```

The analyst is deterministic in its inputs: the client computes every
indicator locally and sends numbers, never raw price arrays, so the model
cannot invent values. Temperature is low. The rendered card shows the exact
input payload on demand.

## 11.2 AI Chat — `/ai/chat`

A conversational surface with the same constraints, plus context awareness: the
current symbol, the user's open positions, and their recent analysis are
offered as attachable context chips the user opts into, never sent silently.
Streaming responses, message history per conversation, and a visible model
name. Tools the chat may call are read-only: fetch indicator values, fetch
digit statistics, fetch the user's own trade statistics. There is no trading
tool and no bot-control tool.

## 11.3 Strategy Assistant — `/ai/strategy`

Helps a user describe a strategy in words and turns it into a **draft** bot
configuration for the builder — entry conditions, exit conditions, stake rule,
risk limits. The draft opens in the builder in an unsaved, unvalidated state
and must pass the builder's own validation before it can run. The assistant
also reviews an existing bot: it reads the block graph and reports missing stop
conditions, unbounded stake growth (martingale detection is explicit and
warned), and untested branches.

## Provider and cost

Model calls run server-side through the AI gateway; no key ever reaches the
browser. Requests are rate limited per user and per minute. Every response
records tokens and latency for the performance doc. Failures degrade to the
raw indicator readout — the deterministic half of the page still renders when
the model is unavailable.

## States

Idle → the inputs panel is populated and the Analyse button is enabled once
enough history has loaded. Insufficient history → the control names how many
ticks are available versus required. Streaming → token-by-token with a stop
control. Rate limited → the remaining cooldown is shown. Model error → the
deterministic readings remain, the interpretation area shows a retry.

## Mobile

Single column: readings first as collapsible rows, interpretation below,
composer pinned to the bottom for chat.
